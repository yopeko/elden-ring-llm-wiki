# 艾爾登法環劇情 LLM Wiki — 維護規則（Schema）

這個資料夾是一個由 LLM 維護、人類審核的知識庫。主題：《艾爾登法環》世界觀與主線劇情（以 YouTube「環學」系列考據影片為來源）。

## 資料夾
- `raw/`：原始資料（環學各集整理稿）。**只讀，不可修改。**
- `wiki/index.md`：所有頁面的目錄，每頁一行＋一句話摘要。每次新增頁面都要更新。
- `wiki/log.md`：時間順序的操作紀錄（ingest / query / lint / 修正），只追加不刪改。
- `wiki/sources/`：每篇 raw 資料一頁摘要。
- `wiki/entities/`：人物、勢力、神祇（例：瑪莉卡、雙指、褪色者）。
- `wiki/concepts/`：抽象概念與設定（例：艾爾登法環、黃金律法、大盧恩、死亡盧恩）。
- `wiki/events/`：歷史事件（例：黑刀陰謀之夜、法環破碎、破碎戰爭）。
- `slides/`：由 Wiki 產生的教學簡報。
- `report/`：繳交用的流程說明、執行紀錄、反思。

## 頁面格式
```markdown
---
type: entity | concept | event | source
aliases: [其他稱呼]
sources: [環學01重製, 環學08]
updated: YYYY-MM-DD
---
# 頁面名稱
> 一句話定義（給完全沒玩過的人看）

## 重點
- 敘述…〔標籤〕 [來源]

## 相關頁面
- [[其他頁面]]

## ⚠ 矛盾與更正（有才寫）
```

## 標籤規則（每一條重點都必須有標籤）
- 〔文本〕：影片中直接引用的遊戲內文字（物品說明、NPC 台詞、真言）。
- 〔考據〕：影片作者的解讀，但影片以肯定語氣陳述。
- 〔推測〕：影片自己標明「推測／或許／可能／發散思維」的內容。
- 不確定屬於哪一類時，往保守方向標（〔考據〕→〔推測〕）。
- 〔文本〕的條目必須真的含有引文（「」或《》），而且引文要能在 raw 找到；同一行如果同時有解讀和引文，要拆成兩條（2026-11-14 加入，見 lint L10）。

## 來源引用格式
`[環學01重製 §區塊三 09:33]`＝集數、區塊、影片時間點。每一條重點至少一個來源。
Wiki 中**不可出現 raw 裡沒有的內容**；我（LLM）自己的遊戲知識不能寫進來。

## 操作
1. **Ingest（先討論、後生成）**：讀一篇 raw → 在對話中提出「重點／要新增或修改的頁面／與現有頁面的衝突」→ 使用者確認或修正 → 才寫入頁面、更新 index、記 log。討論內容存到 `report/ingest討論紀錄.md`。
2. **Query**：回答問題時先讀 `index.md` 找頁面，答案標出所用頁面；有價值的答案可回存成新頁面。
3. **Lint**：每次 ingest 後執行，全部通過才算完成。
   - `py -X utf8 tools/lint.py`：L1 斷連結、L2 沒標籤、L3 沒來源、L4 孤兒頁、L5 引文不在 raw、L6 時間點不存在、L7 raw 沒有的英文詞、L8 index 不一致
   - `py -X utf8 tools/ground.py`：L9 引用對照（重點與所引段落的用字重疊率 < 0.4 → 人工確認）
   - 人工複查：index 摘要是否正確、⚠ 區是否完整（這兩項工具檢查不了）

## 命名
- 一律用台灣譯名（與 raw 一致），檔名＝頁面名稱，例：`wiki/entities/瑪莉卡.md`。

## 衝突處理（2026-11-14 使用者同意，ingest 環學03 時加入）
- 兩集說法不同時，**兩種都保留**：正文以「較新的一集」為準，另一集的說法寫在該頁的「⚠ 矛盾與更正」區，並註明集數。
- 集數新舊：環學01重製 是系列最後一期（DLC 後），比其他所有集數都新；其他依編號先後。
- 若是作者自己在影片中明確更正前說（例：環學08 更正上一期〔環學07〕的「六個圈」為四個圈），舊說法直接標為「已被作者更正」。
